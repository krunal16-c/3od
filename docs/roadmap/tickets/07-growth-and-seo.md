# Ticket 07: Build the growth and SEO engine

**Priority:** P1 — acquisition and learning loop  
**Outcome:** 3oD attracts qualified buyers and vendors through useful content, measurable funnels, and location/process discovery.

## Scope

- Connect Google Search Console and privacy-conscious analytics.
- Track signup, RFQ start, RFQ submission, quote received, and quote accepted events.
- Add India city pages only where real supply or a useful service explanation exists.
- Add process and material landing pages as capabilities become live.
- Publish original guides, project stories, and vendor case studies.
- Add referral and partner acquisition flows.
- Add structured data, canonical URLs, sitemap maintenance, and Core Web Vitals monitoring.

## Acceptance criteria

- Funnel metrics distinguish buyer and vendor journeys.
- No page claims a process is available before the marketplace supports it.
- Every indexable page has a useful title, description, heading structure, and canonical URL.
- Blog posts show authorship, dates, practical experience, and internal links to relevant workflows.
- Search and analytics events do not include passwords, private files, or session tokens.
- Monthly growth experiments are documented with hypothesis, metric, and result.

## Dependencies

Live order data, real vendor supply, analytics consent decision, content ownership.
